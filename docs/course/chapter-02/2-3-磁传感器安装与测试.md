## 一、磁传感器结构与组成

### 1、磁传感器

磁电感应式传感器是一种通过闭合导体的磁通量变化而输出感应电动势的传感器。在不需要电源供电的条件下，直接将被测物体的机械能转换成电信号输出。  
磁传感器具有“双向”性，可作为“逆变器”应用于近年发展起来的“反馈式/力平衡式”传感器中，但其尺寸和重量都比较大。

### 2、磁传感器的分类

基于霍尔效应的磁传感器是利用霍尔元件特性来感知磁场的一类传感器。具有高灵敏度、快速响应和低功耗的特点。

基于霍尔效应的磁传感器

磁电阻传感器是一种利用磁电阻效应来感知磁场的传感器，可用于测量磁场强度、方向等参数。

磁电阻传感器

磁感应传感器

磁感应传感器是一种利用磁感应现象来感知磁场的传感器。磁感应传感器具有高精度、高灵敏度和可靠性好的特点。

磁滞传感器是一种利用磁滞现象来感知磁场的传感器，可以测量磁场的强度和方向。

磁滞传感器

磁光传感器

磁光传感器是一种利用磁光效应来感知磁场的传感器。可以测量磁场的强度、方向等参数。

## 二、磁传感器工作原理与应用

### 1、霍耳效应

以汽车常用霍尔磁敏传感器为例介绍磁传感器工作原理。当电流垂直于外磁场方向通过导体或半导体薄片时,在垂直于电流和磁场方向的两侧产生电势差的现象叫做霍尔效应。

### 教学目标

**素质目标**

1. 具备严谨的工程素养和标准化作业理念，养成“一次做对”的职业习惯；
2. 增强安全责任意识，明确“数据不准=刹车失效”的核心认知；
3. 培育成本意识，树立“装调零失误”的精益作业态度；

**知识目标**

1. 了解磁传感器的基本结构组成（霍尔元件、磁钢、信号处理电路等）及分类方式，区分霍尔式与传统磁电式传感器的结构优势；
2. 理解霍尔效应、磁电阻效应等工作原理，明确装调关键风险点（如间隙控制、磁钢清洁）；
3. 掌握霍尔式轮速传感器安装的间隙标准及安装后信号测试的核心要求；

**能力目标**

1. 能独立完成磁传感器的拆解与组装，准确识别核心部件并做好磁钢清洁保护；
2. 能按规范完成霍尔式轮速传感器安装（间隙控制、固定牢固）与品质检测；
3. 能模拟传感器信号异常场景验证 ABS 系统响应，分析装调过程中常见问题的原因；
4. 能记录完整的装调数据，形成规范的实操报告。

### 教学重点与难点

**教学重点**

1. 磁传感器的结构组成、分类及工作原理；
2. 霍尔式轮速传感器的安装规范（间隙控制）与测试步骤；
3. 严谨态度、成本意识等思政元素在实操中的落地；
4. 霍尔式与传统磁电式传感器的结构对比及优势认知。

**教学难点**

1. 霍尔效应等抽象概念的转化理解；
2. 实操中间隙精准控制及信号异常问题的分析解决；
3. 思政元素与理论、实操教学的自然融合。

### 教学策略

**教学方法**

1. 案例教学法：结合“霍尔式轮速传感器数据错误导致 ABS 系统失效”“装调失误致返工成本增加”等案例，及霍尔式与传统传感器结构对比案例，强化知识与思政认知；
2. 对比教学法：对比霍尔式与传统磁电式传感器结构差异、性能特点，突出霍尔式传感器的技术优势；
3. 任务驱动法：设置“传感器与齿圈间隙为何影响信号输出”“返工一次的时间/材料成本如何计算”等思考任务，引导学生理解规范与成本的核心价值；
4. 讲授法：系统讲解基础概念、技术原理和标准化操作要求。

**教学手段**

1. 多媒体课件：展示力传感器结构图示、爆胎事故数据、国产与进口传感器对比图、应用场景视频等；
2. 仿真软件：模拟传感器数据采集、胎压异常报警及装调故障场景，增强直观体验；
3. 小组讨论：围绕案例和思考任务开展互动交流，深化对原理、规范和思政元素的理解；
4. 实物教具：展示霍尔式轮速传感器、磁电式传感器、齿圈等实物，结合讲解其结构与工作原理。
